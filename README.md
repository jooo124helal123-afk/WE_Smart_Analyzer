# 🌐 WE Smart Analyzer - المحلل الذكي لباقة WE

مشروع ويب تفاعلي مصمم للمساعدة في إدارة وتوزيع استهلاك باقة الإنترنت المنزلية بذكاء بناءً على الأيام المتبقية وأولويات التطبيقات.

---

## 🚀 المميزات الرئيسية
* **التحليل الذكي العام:** حساب معدل السحب الفعلي مقارنة بالمستهدف اليومي.
* **إدارة أولويات التطبيقات:** تحديد سقف استهلاك لكل تطبيق لتجنب نفاذ الباقة.
* **نظام حماية للمطور (Admin Panel):** لوحة تحكم سرية بنظام مصادقة وتشفير لإضافة تطبيقات جديدة.
* **تصميم عصري (Responsive UI):** واجهة متوافقة مع الهواتف بدعم للـ Dark Mode.
